# ChatCactus Web Widget & SDK

Official embed script and client-side integration guidelines for [ChatCactus](https://chatcactus.com) — an intelligent AI-powered live chat platform for customer support.

## Overview
ChatCactus helps businesses automate customer conversations, capture qualified leads, and resolve user queries 24/7 with zero latency. 

Visit our official site: [https://chatcactus.com](https://chatcactus.com)

---

## Quick Installation

Add the following script snippet to your HTML just before the closing `</body>` tag:

```html
<script 
  src="[https://cdn.chatcactus.com/widget.js](https://cdn.chatcactus.com/widget.js)" 
  data-chatcactus-id="YOUR_PROJECT_ID" 
  async>
</script>
